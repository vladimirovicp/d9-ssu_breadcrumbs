# SSU Breadcrumbs

Drupal 9 модуль для построения кастомных хлебных крошек на страницах материалов типа **news**.

## Описание

Модуль заменяет стандартные хлебные крошки Drupal на кастомные для нод типа `news`, используя иерархию родительских ссылок. Цепочка навигации строится на основе полей `field_news_link` и `field_parent_link`, формируя путь от корневого раздела до текущей новости.

## Требования

- Drupal 9
- Тип материала `news` с полем `field_news_link` (Entity Reference)
- Поле `field_parent_link` (Entity Reference) на связанных сущностях для построения родительской цепочки
- Нода с ID **759** («Структура») — корневой элемент иерархии

## Установка

1. Разместите модуль в директории `modules/custom/ssu_breadcrumbs`.
2. Включите модуль:

```bash
drush en ssu_breadcrumbs
```

## Принцип работы

### Условия применения

Хлебные крошки строятся только при выполнении всех условий:

- Маршрут страницы — `entity.node.canonical` (полная страница ноды)
- Тип материала — `news`
- Поле `field_news_link` заполнено

### Алгоритм построения цепочки

1. **Главная** — ссылка на главную страницу сайта (всегда первый элемент)
2. **Родительская цепочка** — рекурсивный обход по `field_parent_link` от связанной сущности из `field_news_link` до корневого узла (нода 759 «Структура»). Элементы выводятся в порядке LIFO: сначала корневой, затем дочерние
3. **Новости** — ссылка вида `<URL последнего родителя>/news`
4. **Заголовок текущей ноды** — текст без ссылки (последний элемент)

### Пример результата

```
Главная > Структура > Факультет > Кафедра > Новости > Заголовок новости
```

## Архитектура

### Файловая структура

```
ssu_breadcrumbs/

├── ssu_breadcrumbs.services.yml      # Определение сервиса
├── src/
│   └── Breadcrumb/
│       └── ParentNodeBreadcrumbBuilder.php  # Билдер хлебных крошек
└── README.md
```

### Сервис

Модуль регистрирует единственный сервис `ssu_breadcrumbs.breadcrumb` с тегом `breadcrumb_builder` и приоритетом **1001**, что обеспечивает его выполнение перед стандартными билдерами Drupal.

| Параметр | Значение |
|----------|----------|
| Класс | `Drupal\ssu_breadcrumbs\Breadcrumb\ParentNodeBreadcrumbBuilder` |
| Зависимость | `@entity_type.manager` |
| Тег | `breadcrumb_builder` |
| Приоритет | `1001` |

### Класс ParentNodeBreadcrumbBuilder

Реализует интерфейс `BreadcrumbBuilderInterface` и содержит три метода:

| Метод | Описание |
|-------|----------|
| `applies()` | Проверяет, что текущая страница — каноническая нода типа `news` с заполненным `field_news_link` |
| `build()` | Формирует объект `Breadcrumb` с полной цепочкой навигации |
| `processLinkedEntity()` | Рекурсивно обходит родительские сущности через `field_parent_link` до ноды 759 |

### Кеширование

Хлебные крошки кешируются по контексту `url.path`, что обеспечивает уникальный кеш для каждой страницы.

## Зависимости от контента

| Сущность / Поле | Назначение |
|------------------|-----------|
| Тип материала `news` | Целевой тип для построения хлебных крошек |
| `field_news_link` | Ссылка на родительскую структурную единицу новости |
| `field_parent_link` | Ссылка на вышестоящий элемент иерархии |
| Нода ID 759 | Корневой узел «Структура», точка остановки рекурсии |
